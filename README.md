## Features

* **⚡ Direkte API-Anbindung:** Kein unnötiger Ballast, direkter Zugriff auf Gemini Flash und Pro Modelle.
* **⚙️ Flexibles Settings-Management:** Konfiguriere API-Key, Sicherheitsfilter (Bypass Mode) und Auto-Accept direkt über die Sidebar oder das Dashboard.
* **🚀 Dashboard-Ansicht:** Eine vollwertige Webview-Oberfläche im Editor-Stil für maximale Produktivität.
* **🛡️ Volle Kontrolle:** Du bestimmst, welches Modell abgefragt wird – komplett ohne künstliche Limits.

---

## Verwendung

1. Installiere die Extension.
2. Öffne das **Coding Forever** Icon in der Activity Bar (links).
3. Trage über das Zahnrad deinen Google Gemini API Key ein.
4. Wähle dein gewünschtes Modell und starte mit dem Coding!

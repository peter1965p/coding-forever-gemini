# Coding Forever

**Direct Gemini Flash Integration without Limits** — Die ultimative VS Code Extension für ungedrosselte KI-Entwicklung, angetrieben direkt von der Google Gemini API. Coding wie Du es willst!

## Features

* Direkte API-Anbindung: Kein unnötiges Abo und keine Kosten, direkter Zugriff auf Gemini Flash und Pro Modelle.
* Flexibles Settings-Management: Konfiguriere API-Key für Gemini oder Lokale Modelle wie Ollama. 
* Sicherheitsfilter: Bypass Mode und Auto-Accept direkt über Einstellungen oder den Chat aktivierbar.
* Dashboard-Ansicht: Eine vollwertige Webview-Oberfläche im Editor-Stil für maximale Produktivität.
* Volle Kontrolle: Du bestimmst, welches Modell abgefragt wird – komplett ohne künstliche Limits.
* Prompt Manager: Der neue Prompt Manager bietet Dir vordefinierte Prompts die Du sofort nutzen kannst.   

---

## Verwendung

1. Installiere die Extension.
2. Öffne das **Coding Forever** Icon in der Activity Bar.
3. Trage über das Zahnrad deinen Google Gemini API Key ein. 
4. Den findest Du hier: https://aistudio.google.com/api-keys
5. Wähle dein gewünschtes Modell und starte mit dem Coding!
